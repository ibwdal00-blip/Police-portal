# Discord Stats Bot

بوت ديسكورد لإدارة 3 إحصائيات:

- الريبورت
- السحبات
- المراقبة الدورية

## الأزرار

1. **حسب الريبورت** → يضيف +1 للريبورت.
2. **حسب السحبات** → يضيف +1 للسحبات.
3. **حسب المراقبة الدورية** → يضيف +1 للمراقبة.
4. **إضافة رقم** → تختار القائمة وتدخل أي رقم.

## التقارير

- يوميًا الساعة **11:00 صباحًا بتوقيت الرياض**.
- كل أربعاء الساعة **11:00 صباحًا بتوقيت الرياض** يتم إرسال التقرير الأسبوعي.
- بعد التقرير اليومي يتم تصفير العداد اليومي.
- بعد التقرير الأسبوعي يتم تصفير العداد الأسبوعي.

البيانات محفوظة في SQLite داخل `stats.db`، لذلك لا تضيع عند إعادة تشغيل البوت.

## التشغيل

### 1) ثبّت Python 3.11 أو أحدث

### 2) افتح Terminal داخل مجلد المشروع

```bash
pip install -r requirements.txt
```

### 3) انسخ `.env.example` إلى `.env`

ثم ضع:

```env
DISCORD_TOKEN=توكن_البوت
REPORT_CHANNEL_ID=ايدي_قناة_التقارير
TIMEZONE=Asia/Riyadh
```

### 4) شغّل البوت

```bash
python bot.py
```

### 5) داخل السيرفر

استخدم:

```text
/setup
```

وسيتم إرسال لوحة الأزرار.

## صلاحيات البوت

البوت يحتاج على الأقل:

- View Channel
- Send Messages
- Embed Links
- Use Application Commands

وللأزرار والتفاعل يجب أن يكون قادرًا على إرسال رسائل في القناة التي توجد فيها اللوحة.
