# 🤖 بوت عداد السحبات (Discord Bot)

بوت ديسكورد كامل يعرض لوحة تفاعلية بعداد يمكن التحكم فيه بالأزرار،
مع تقارير يومية وأسبوعية تلقائية، وحفظ دائم للبيانات.

## المميزات
- أمر واحد `/لوحة` يرسل لوحة تفاعلية، وتختار نوعها من قائمة: **عداد السحب** أو **عداد المراقبة الدورية**
- كل عداد مستقل تمامًا عن الثاني: رقمه الخاص، وأزراره الخاصة (إضافة ➕ / حذف ➖ / تحديد رقم ✏️)
- الأزرار تشتغل فقط لمن يملك رتبة الدعم (أو صلاحية مدير)
- **سجل عمليات فوري**: كل ضغطة زر (إضافة/حذف/تحديد رقم) تترسل كسطر تقرير مباشرة في قناة مخصصة، فيه: نوع العملية، مين سواها، القيمة قبل/بعد، والوقت
- كل يوم الساعة **11:00 مساءً بتوقيت الرياض** يُرسل تقرير اليوم لكل عداد على حدة ويُصفَّر عداد اليوم لكل واحد منهما
- كل **أربعاء** الساعة **11:00 مساءً** يُرسل تقرير أسبوعي إضافي لكل عداد ويُصفَّر عداد الأسبوع لكل واحد منهما
- البيانات تُحفظ في ملف `data.json` فتبقى محفوظة حتى لو تم إيقاف/إعادة تشغيل البوت
- تصميم Embed مرتب لكل عداد بلونه الخاص

---

## 1) إنشاء البوت في Discord Developer Portal
1. ادخل على: https://discord.com/developers/applications
2. اضغط **New Application** واختر اسمًا.
3. من تبويب **Bot** اضغط **Reset Token** وانسخ التوكن (سيُستخدم لاحقًا في `DISCORD_TOKEN`).
4. في نفس صفحة **Bot**، فعّل:
   - `SERVER MEMBERS INTENT`
5. من تبويب **OAuth2 → URL Generator**:
   - في **Scopes** اختر: `bot` و `applications.commands`
   - في **Bot Permissions** اختر: `Send Messages`, `Embed Links`, `Read Message History`, `Manage Messages` (اختياري)
   - انسخ الرابط الناتج وافتحه لدعوة البوت لسيرفرك.

---

## 2) التشغيل محليًا (اختياري للتجربة)
```bash
pip install -r requirements.txt
cp .env.example .env
# افتح .env وضع التوكن الحقيقي بجانب DISCORD_TOKEN
python bot.py
```

---

## 3) رفع البوت على Render (يعمل 24/7)

### الطريقة المفضّلة: Background Worker
1. ادخل على https://render.com وأنشئ حساب واربطه بمستودع GitHub يحتوي هذه الملفات.
2. اضغط **New +** → **Background Worker**.
3. اختر المستودع، ثم:
   - **Build Command**: `pip install -r requirements.txt`
   - **Start Command**: `python bot.py`
4. من تبويب **Environment**، أضف متغير:
   - `DISCORD_TOKEN` = التوكن الخاص بالبوت
5. اضغط **Deploy**.

> ملاحظة: خدمة Background Worker على Render ليست ضمن الخطة المجانية دائمًا،
> تحقق من الأسعار الحالية على render.com.

### إذا استخدمت Web Service (خطة مجانية)
خطة الويب المجانية "تُنيم" التطبيق إذا ما استقبل زيارات. لتفادي ذلك:
1. أضف بالأعلى في `bot.py`:
   ```python
   from keep_alive import keep_alive
   ```
2. أضف قبل `bot.run(TOKEN)`:
   ```python
   keep_alive()
   ```
3. بعد النشر، انسخ رابط الخدمة (مثل `https://your-bot.onrender.com`)
   واستخدم موقع مثل **UptimeRobot** (مجاني) لعمل بينغ على الرابط كل 5 دقائق حتى لا ينام البوت.

## 4) إعداد البوت داخل السيرفر
بعد ما يشتغل البوت وينضم للسيرفر:
1. نفّذ الأمر `/تحديد_الرتبة` واختر رتبة الدعم المسموح لها استخدام الأزرار (يتطلب صلاحية مدير).
2. (اختياري) نفّذ `/تحديد_قناة_التقارير` لتحديد قناة مخصصة لإرسال كل التقارير اليومية/الأسبوعية (لعداد السحب وعداد المراقبة معًا).
   إذا لم تحددها، سيتم إرسال تقرير كل عداد في نفس قناة لوحته.
3. (اختياري) نفّذ `/تحديد_قناة_السجل` واختر قناة (يفضّل تكون خاصة بالإدارة/الدعم) ليتم تسجيل كل ضغطة زر فيها فورًا.
   إذا لم تحددها، لن يتم تسجيل أي عملية (السجل معطّل افتراضيًا).
4. نفّذ `/لوحة` واختر من القائمة **عداد السحب** في القناة المناسبة.
5. نفّذ `/لوحة` مرة ثانية واختر **عداد المراقبة الدورية** في القناة المناسبة (تقدر تكون نفس القناة أو قناة مختلفة).

## 5) هيكل الملفات
```
discord-bot/
├── bot.py              # الملف الرئيسي للبوت
├── storage.py           # حفظ واسترجاع البيانات من data.json
├── keep_alive.py         # سيرفر ويب اختياري (Render Web Service فقط)
├── requirements.txt      # المكتبات المطلوبة
├── .env.example          # نموذج لملف المتغيرات البيئية
├── data.json             # قاعدة بيانات بسيطة (تُنشأ/تُحدَّث تلقائيًا)
└── README.md
```

## ملاحظات مهمة
- توقيت التصفير والتقارير مضبوط على **توقيت الرياض (Asia/Riyadh)**، غيّره في `bot.py` (متغير `TZ`) إذا لزم.
- إذا غيّرت اسم أمر `/لوحة` أو أضفت أوامر جديدة، أعد تشغيل البوت ليتم مزامنتها مع Discord.
- عند التجربة الأولى، يفضّل وضع `GUILD_ID` في `.env` لمزامنة الأوامر فورًا بدل الانتظار حتى ساعة (المزامنة العالمية).
- لا تشارك ملف `.env` أو التوكن مع أي أحد.
